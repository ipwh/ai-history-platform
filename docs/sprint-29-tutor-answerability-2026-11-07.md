## 1. 執行結論

本 Sprint 修正了一類**架構性假拒絕**：教材檢索失敗（詞庫／課程關鍵詞沒有逐字命中）原本會直接把可理解的歷史提問變成「只能討論歷史科」的固定拒答。現在檢索成敗與「是否可答」分開，並以四個明確狀態（A／B／C／D）決定回覆政策；C 狀態**必須作答**，同時清楚標明一般歷史知識，禁止虛構出處。

同時修正了三個決策邊界：英文疑問詞誤命中詞庫別名（WHO）、任何年份都被當成歷史訊號、以及粵語評價／追問句式未被深度判斷識別。

**發布判定：`READY WITH DOCUMENTED LIMITATIONS`（程式與政策層），不是 `READY`。** 學伴回覆的歷史正確性、教學質素及語言質素**全部仍待歷史科教師覆核**；本輪沒有（也不應在未授權下）執行受控的模型輸出取樣評估，因此不能宣稱「已無歷史 misinformation 風險」。

## 3. 提問難度覆蓋

35 類提問（規格 §4）**每類至少兩條案例、至少兩個難度層級**（契約測試強制）：

- `recall`：辨識型史實／定義／時序 → 只接受 `standard`；
- `explain`：背景／原因／後果／意義說明 → 接受 `standard` 或 `advanced`；
- `analyse`：多重成因、比較、兩事因果、過程 → 只接受 `advanced`；
- `evaluate`：評價、成功失敗、相對重要性、多大程度、史學詮釋 → 只接受 `challenge`。

深度只由提問的認知要求決定，並可由學生覆寫；短追問沿用上一輪深度；「越深」不等於「越長」（`advanced` 450–700 字、`challenge` 600–900 字、`standard` 四段精簡）。

## 5. 歷史答案品質發現

- 本輪**沒有**產生或評分任何真實模型回覆（未獲授權的受控取樣），因此無法聲稱歷史上「無錯誤」。
- 已建立 15 項 0–4 分評分表（史實、時序、因果、脈絡、概念、完整度、切題、難度、清晰、證據、證據與推論之分、不確定處理、錯誤前提更正、追問連貫、繁體書面語），並明文規定「流暢或自信的措辭不可抵銷史實錯誤」。
- 提示詞層面已強化：C 狀態必須標明一般歷史知識；B 狀態先答教材支持部分再披露缺口；任何狀態禁止虛構課本段落、引文、頁數、出處或評分標準。
- **所有歷史內容判斷仍待教師逐題覆核**（83 條矩陣 + 78 條模擬矩陣）。

## 6. 檢索與證據政策發現

1. **四態政策**（新增 [tutor-answerability.ts](../src/server/services/tutor-answerability.ts)、[tutor-answerability-prompt.ts](../src/server/services/tutor-answerability-prompt.ts)）：A 教材支持；B 部分支持；C 教材未涵蓋但必須作答；D 真正含混只澄清。另有 `out-of-scope`（明確非歷史）沿用原有引導句。
2. **沒有移除檢索門檻**：低分段落仍被排除；C 狀態只改用「標明為一般歷史知識」的答案，不會把無關段落當成依據，也不會令檢索失敗變成假依據。
3. **狀態判斷與檢索分離**：判斷只依賴「是否歷史提問」＋「教材涵蓋程度」＋「是否含混」，因此同一個問題在教材分佈改變時只會由 C 變成 A/B，不會反過來變成拒絕。
4. **檢索限制仍然存在**：字詞比對召回率不及語意檢索；英文連接詞會切斷專名；課題推斷未按年級分流。

## 12. 仍然存在的限制

1. **歷史正確性未經教師確認**：C 狀態的一般歷史知識由模型提供，系統只能約束標示與禁止虛構，不能保證內容準確。
2. **沒有實測模型輸出**：未經授權，沒有執行受控的模型取樣評估；因此「無歷史 misinformation 回歸」未能以實測支持，只能以提示詞契約及確定性測試支持。
3. **模擬矩陣是測試替身**：以「教材涵蓋程度」模擬檢索結果，不代表真實教材分佈下的召回率。
4. **檢索仍是字詞比對**：換句問法可能找不到片段（此時走 C，不會拒答，但可能少了課本依據）；英文連接詞會切斷專名。
5. **正式環境未重新驗證**：`gcloud` 需互動式重新認證，未核實 Cloud Run revision／流量；沒有授權測試帳戶驗證登入學生的實際回覆。
6. **CI 未跑候選版本**：未推送，故沒有候選 commit 的 CI 證據。
7. **長對話及學習技巧類提問**：`DSE 比較題應該點答？` 仍走澄清（既有產品定位未決）。
