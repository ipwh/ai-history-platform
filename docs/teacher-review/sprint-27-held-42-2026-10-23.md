## 1. 分類規則（先看規則，再看逐題）

每題只有一個建議標籤，依下列**優先次序**判定，每項都可核查：

| 次序 | 條件 | 標籤 | 意思 |
| --- | --- | --- | --- |
| 1 | 所引用的教材段落 ID 已不在 `material_blocks` | `SOURCE_EVIDENCE_MISSING` | 教材重新匯入後 block ID 失效，題目失去可核對依據 |
| 2 | 題幹已列出 ≥2 個年份，且題目要求排列先後 | `CORRECTION_PROPOSED` | 學生只須比較數字即可作答，題目沒有考核時序 |
| 3 | 答案逐字見於所引段落，但被歷史元素檢查標為「非歷史元素」（簡稱） | `TEACHER_DECISION_REQUIRED` | 須教師確認是否接受簡稱寫法 |
| 4 | 答案逐字見於所引段落，警告只涉及改寫相似度 | `FACTUALLY_SUPPORTED` | 教材直接支持答案 |
| 5 | 警告涉及「唯一／首先／因此／因為／教材沒有提供比較」 | `AMBIGUOUS_OR_UNDERSUPPORTED` | 解釋中的因果／排他／比較判斷在所引段落中沒有依據 |
| 6 | 其餘（答案為改寫、涉及教學判斷） | `TEACHER_DECISION_REQUIRED` | 須教師核對教材後決定 |

**標籤只描述證據狀態，不代表史實對錯。** `FACTUALLY_SUPPORTED` 只表示「教材逐字支持
這個答案」，仍須教師判斷是否適合該級別學生；`SOURCE_EVIDENCE_MISSING` 不代表題目內容
有錯，只代表無從核對。

## 5. 教師處理方式（不得由程式代辦）

每一題只能由歷史科教師在「教師審核」介面處理：

1. **核對教材**：按題目所指的教材段落（若已失效，先重新指定段落）；
2. **作出決定**：覆核通過（會寫入 `question_reviews`，綁定目前 revision 及內容指紋）、退回修正，或停用；
3. **理由必須由教師填寫**：不可由系統生成「已核對」「答案正確」等字句。

程式**不會**、亦**不應**為這 42 題：自動批准、批量發布、偽造覆核紀錄、或以重跑自動驗證代替教師決定。

完成後驗證：

```bash
npm run audit:governance-evidence   # teacherConfirmationRequired 應由 42 下降
npm run release:gate                # question-isolation 應由 FAIL 轉 PASS
```
